# Polymuh: Симуляция зрительно-моторного контура дрозофилы (FlyWire) для Polytrack

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![PyTorch](https://img.shields.io/badge/PyTorch-2.0+-ee4c2c.svg)](https://pytorch.org/)
[![Connectome: FlyWire](https://img.shields.io/badge/Connectome-FlyWire%20v783-brightgreen.svg)](https://codex.flywire.ai/)

Программный комплекс на Python для автономного управления автомобилем в гоночной игре **[Polytrack](https://kodub.itch.io/polytrack)** от разработчика **[kodub](https://kodub.itch.io)** на основе биофизической симуляции фрагмента реального коннектома мозга плодовой мушки (*Drosophila melanogaster*) из базы данных **FlyWire**.

---

## О проекте и игре

- **Игра:** **[Polytrack](https://kodub.itch.io/polytrack)** — динамичная низкополигональная гоночная игра с реалистичной физикой и сложными треками.
- **Автор игры:** **[kodub](https://kodub.itch.io)** (itch.io).
- Проект поддерживает как **Desktop-приложение Polytrack** (автоматический захват окна игры через Win32 Client Rectangle без рамок и заголовков), так и браузерную версию.

---

## Архитектура контура

Система реализует замкнутый биологический контур управления (Closed-Loop Vision-Motor System):

```
+----------------------------------------------------------------------------------------------------+
|                                    ИГРА POLYTRACK (Desktop-окно)                                   |
+----------------------------------------------------------------------------------------------------+
              │ Захват кадра (mss, ClientRect, ~3.8 мс)              ▲ Эмуляция WASD (pynput, ~0.15 мс)
              ▼                                                      │
+--------------------------------------------+         +--------------------------------------------+
|    МОДУЛЬ 1: Game Harness & Game State     |         |         МОДУЛЬ 5: Моторный декодер         |
|    - ScreenCapture (Desktop / ClientRect)  |         |         - Частота спайков DN -> WASD       |
|    - Детекция падения (трава >= 35%)       |         |           * DNa01 / DNa02 -> Руль (A / D)  |
|    - Детектор застревания (stuck_motion)   |         |           * DNp01         -> Газ  (W)      |
+--------------------------------------------+         |           * DNb01         -> Тормоз (S)    |
              │                                        |         - PD-демпфирование сноса (D-term)  |
              ▼                                        |         - Триггер Шмитта и гистерезис      |
+--------------------------------------------+         |         - Пауза нейтрали (Cadence Lockout) |
|     МОДУЛЬ 2: Сетчатка (retina.py)         |         +--------------------------------------------+
|     - Бинокулярная сетка (16x32 омматидиев)|                               ▲
|     - ON/OFF каналы (клетки L1/L2 -> T4/T5)|                               │ Спайки DN
|     - 2D детекторы движения (HRC / EMD)    |                               │
|     - LPTC клетки (HS: рыскание, VS: ход)  |         +--------------------------------------------+
+--------------------------------------------+         | МОДУЛЬ 4: Спайковый мозг (fly_brain.py)    |
              │                                        | - Векторизованная LIF-модель на PyTorch    |
              ▼                                        |   (утечка, порог V_th, сброс V_reset)      |
+--------------------------------------------+         | - 102 биологических нейрона (FlyWire)      |
| МОДУЛЬ 3: Детектор поребриков и геометрии  |         | - E-PG кольцевой компас ориентации 360°    |
| - Поребрики (красно-белые шашки PolyTrack) |         | - P-EN интеграторы угловой скорости        |
| - Оптимальный коридор и центрирование      |         | - Delta7 ГАМК-торможение кольца            |
| - Детекция сужений и бутылочных горлышек   |         +--------------------------------------------+
| - Зависание на поребрике (beached/breach)  |                               ▲
+--------------------------------------------+                               │
              │ Токи стимуляции I_ext + коридор                              │
              ▼                                                              │
+--------------------------------------------+                               │
| Пластический адаптер (RF 2D-гауссианы)     |───────────────────────────────┘
+--------------------------------------------+
              │
              ▼
+----------------------------------------------------------------------------------------------------+
| МОДУЛЬ 6: Прозрачный оверлей коннектома (neural_overlay.py)                                       |
| - Аппаратная маскировка Win32 WDA_EXCLUDEFROMCAPTURE (виден игроку, невидим для захвата бота)      |
| - Отображение LPTC, компаса E-PG, спайков DN и педалей WASD в реальном времени                     |
+----------------------------------------------------------------------------------------------------+
```

## Модули системы

### 1. Game Harness & Input/Output (`game_harness.py`)
- **Захват кадров:** интеграция с `mss`, прямое чтение буфера в NumPy (~3.8 мс).
- **Поддержка Desktop-приложения Polytrack:** автоматический расчет клиентской области окна через Win32 `GetClientRect` и `ClientToScreen` для отсечения системных заголовков и рамок.
- **Эмуляция ввода:** `pynput.keyboard.Controller` с кэшированием состояний (устраняет спам в очередь ОС) и безопасным сбросом (`release_all`) через `atexit`.
- **Надёжная детекция падения с эстакады:** распознавание зелёной травы в нижних 45% экрана ($\ge 35\%$). Исключена слепота из-за кузова автомобиля или размытости пустоты.
- **Фильтрация артефактов:** тикающий внутриигровой таймер PolyTrack полностью исключён из формулы физического движения.
- **Детектор застревания в стене (`stuck_motionless`):** требует реального физического расширения оптического потока ($vs\_forward > 0.0008$). Если газ W зажат, а болид упёрся в препятствие $> 45$ кадров (~0.8 сек), попытка мгновенно штрафуется и перезапускается.

### 2. Сетчатка и зрительный препроцессинг (`retina.py`)
- **Фасеточный глаз:** $16 \times 32$ омматидия (2 глаза по $16 \times 16$), гауссово оптическое размытие ($\Delta \rho \approx 5^\circ$) и спектральная чувствительность родопсина Rh1.
- **Нелинейная компрессия:** биофизическое уравнение Нака–Раштона $V = \frac{I}{I + I_{50}}$.
- **ON/OFF пути:** раздельное выделение фронтов нарастания ($\Delta I^+$) и спада ($\Delta I^-$) освещенности (прототипы клеток T4/T5).
- **Детекторы Хассенштейна–Райхардта (2D HRC):** вычисление покадрового движения $\text{EMD}_x$ (горизонтальное) и $\text{EMD}_y$ (вертикальное).
- **Тангенциальные клетки LPTC:** интегральные сигналы `HS-Left`, `HS-Right` (рыскание Yaw) и `VS-Forward` (радиальное расширение оптического потока из Focus of Expansion, FOE).
- **Синтез токов:** формирование вектора стимуляции для пластического адаптера SNN.
- **Интерактивный дашборд:** композитный интерфейс 1280x760 px с показом вида глазами мухи, векторов оптического потока и растра спайков.

### 3. Детектор поребриков и геометрии трассы (`boundary_detector.py`)
- **Высокоскоростное распознавание поребриков:** сканирование характерных красно-белых шашечных текстур PolyTrack в цветовом пространстве HSV.
- **Метрики центрирования и коридора:**
  - `lateral_offset`: непрерывное отклонение от центра трассы $[-1.0 \dots +1.0]$.
  - `track_heading_deg` и `immediate_heading_deg`: угол направления дороги на горизонте и в ближней зоне (5–15 м).
  - `proximity_left` / `proximity_right`: коэффициент опасности столкновения с бортами.
- **Детекция бутылочных горлышек (Bottlenecks):** анализ сужения апертуры трассы (`aperture_ratio < 0.70`), превентивное распознавание шикан с расчётом `constriction_risk` для заблаговременного трейл-брейкинга.
- **Физическая детекция выхода за пределы трассы:**
  - `is_curb_breached`: пересечение внешнего края поребрика ($|norm\_pos| > 1.15$).
  - `is_curb_beached`: зависание болида брюхом на бортике ($|norm\_pos| \in [0.85, 1.25]$ при нулевой скорости).
- **Антифликкерная фильтрация:** сглаживание шашечного мерцания текстур ($\alpha = 0.50$) с мгновенным сбросом при респауне болида ($|\Delta| > 0.35$).

### 4. Экстракция и топология коннектома FlyWire (`connectome_loader.py`)
- **Биологический подграф (102 нейрона, 376 синапсов):**
  - *Входной слой (26 нейронов LPTC):* `HS_L_*`, `HS_R_*`, `VS_L_01..10`, `VS_R_01..10`.
  - *Центральный комплекс (68 нейронов CX):* кольцевой компас `E-PG` (16 клиньев), интеграторы скорости поворота `P-EN` (16 клеток), тормозные ГАМК-интернейроны `Delta7` (8 клеток), петля `P-EG` (16 клеток), моторные проекции `PFL3` (12 клеток).
  - *Моторный выход (8 нисходящих нейронов DN):* рулевые `DNa01/DNa02`, тяговые `DNp01`, тормозные `DNb01`.
- **Знаки синапсов:** возбуждающие холинергические ($+1.0$) и тормозные ГАМК/глутаматергические ($-1.0$).
- **Кэширование:** матрица смежности сохраняется локально в `data/connectome/flywire_subgraph.npz`.

### 5. Спайковая нейросеть и стабилизация руления (`fly_brain.py`)
- **Векторизованная LIF-динамика на PyTorch:**
  $$V_i[t] = \alpha V_i[t-1] + \sum_j W_{ji} S_j[t-1] \cdot g_{\text{syn}} + I_{\text{ext}, i}[t]$$
  Интеграция $K = 8$ подшагов на кадр (~2 мс биофизического времени, >330 FPS).
- **Биологический компас E-PG (Central Complex):** фазовый бугор активности (bump attractor) на кольце из 16 клиньев кодирует текущее направление трассы, направляя возбуждение через PFL3 на рулевые нейроны DNa и подавляя газ DNp перед опасными углами.
- **Полная ликвидация рыскания и дребезга клавиш (A-D Anti-Chatter):**
  - *PD-демпфирование сноса:* производная скорости $\text{drift\_rate} = \Delta \text{offset}$ гасит руление при приближении к центру трассы, устраняя перелёт за осевую (Overshoot).
  - *Триггер Шмитта с гистерезисом:* порог включения $P_{\text{ON}} = 0.51$, порог удержания $P_{\text{OFF}} = 0.44$. Исключает высокочастотное мигание клавиш.
  - *Пауза нейтрали (Neutral Cadence Lockout):* при смене направления ($A \leftrightarrow D$) выдерживается обязательная 2-кадровая пауза (~33 мс), позволяющая виртуальной рейке болида отцентрироваться без раскачки.
  - *Emergency Wall Override:* при критической опасности борта ($\text{proximity} > 0.70$) пауза нейтрали мгновенно отменяется для спасения от удара.
  - *Трейл-брейкинг (Trail Braking):* контролируемое одновременное зажатие W и S в крутых поворотах для силового заноса без ухода в реверс.

### 6. Прозрачный оверлей коннектома над окном игры (`neural_overlay.py`)
- **Автономный неблокирующий HUD:** запускается в отдельном процессе `multiprocessing.Process` через очередь `mp.Queue(maxsize=4)` с частотой 60 FPS.
- **Привязка к окну PolyTrack:** размещается строго посередине правого края игрового окна, динамически отслеживая его перемещение и масштабирование.
- **Аппаратная маскировка Win32:** флаг `WDA_EXCLUDEFROMCAPTURE` (0x11) делает оверлей видимым для игрока, но **100% невидимым для экранного захвата бота (`mss` / BitBlt)** — зрение мухи остаётся абсолютно чистым.
- **Сквозной клик:** флаг `WS_EX_TRANSPARENT` позволяет кликать мышью сквозь элементы оверлея в окно игры.
- **Живая визуализация:** LPTC-нейроны зрительных долей (HS/VS), вращающийся золотистый бугор компаса E-PG, спайки нисходящих нейронов DN, динамические индикаторы нажатия клавиш WASD.

### 7. Эволюционный тренер и сжатие генотипа (`trainer.py`)
- **Сжатие генотипа до 170 параметров (Genotype Compression):** замена плотной матрицы $2004 \times 26$ на параметрические 2D-гауссианы рецептивных полей (RF, по 5 параметров на LPTC-нейрон). Генотип сжат более чем в 300 раз (170 вместо 52 166 параметров), что обеспечивает быструю сходимость эволюции.
- **Специация по 3 поведенческим нишам:**
  - `speedrunner`: максимизация поступательного оптического потока и темпа.
  - `centrist`: минимизация отклонения от осевой линии и штраф за бортики.
  - `drifter`: скоростное прохождение поворотов по апексам поребриков.
- **Честный внутрипоколенческий отбор:** лучший мутант поколения, опередивший чемпиона, немедленно объявляется новым чемпионом и сохраняется в `data/brain_weights_best.pt`.
- **Динамический овертайм (Endurance Extension):** автоматическое продление заезда (+250 кадров, вплоть до 2500 кадров), если болид успешно держит трассу и продолжает движение.
- **Фоновый синтетический бутстрап (`10_BOOTSTRAP_BRAIN.bat`):** проведение 100 поколений эволюции в фоне за 1 минуту перед выходом на реальную трассу.

## Запуск в один клик (Windows BAT-файлы)

Для удобного запуска ключевых функций без необходимости вводить команды в терминале в корень проекта добавлены готовые `.bat` скрипты:

- **`1_CALIBRATE_WINDOW.bat`** — Автоматический поиск или интерактивная калибровка области окна Desktop Polytrack.
- **`2_RUN_AUTOPILOT.bat`** — Запуск автономного автопилота мухи в живом окне игры Polytrack с прозрачным оверлеем коннектома и весами `data/brain_weights_best.pt`.
- **`3_RUN_SYNTHETIC_DEMO.bat`** — Демонстрационная симуляция с синтетическим треком Polytrack (без запуска игры).
- **`4_TRAIN_AGENT.bat`** — Эволюционное обучение пластических слоев мухи (с настраиваемой длительностью, овертаймом и живым оверлеем).
- **`5_VIEW_RETINA_DASHBOARD.bat`** — Запуск интерактивной панели зрительной системы мухи с прямым захватом живого экрана PolyTrack.
- **`6_BENCHMARK_LATENCY.bat`** — Запуск бенчмарка задержки (проверка соответствия бюджету $\le 30\text{--}40$ мс).
- **`7_RUN_ALL_TESTS.bat`** — Запуск полного набора тестов по всем модулям системы (8 наборов тестов).
- **`8_MANAGE_BRAIN.bat`** — Интерактивное меню управления мозгом дрозофилы: сброс до исходного состояния, откат к прошлой сессии, архив чекпоинтов.
- **`9_CHECK_FLY_VISION.bat`** — Экспресс-диагностика зрения мухи с генерацией коллажа-доказательства `data/fly_sight_diagnostic.png`.
- **`10_BOOTSTRAP_BRAIN.bat`** — Фоновый синтетический бутстрап мозга за 1 минуту перед запуском живой игры.

## Установка и быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/whoami-28/fly-track.git
cd fly-track
pip install -r requirements.txt
```

### 2. Настройка окружения (`.env`)
Файл `.env` уже преднастроен с оптимальными параметрами по умолчанию:
```ini
DEVICE=cpu
WINDOW_KEYWORD=Polytrack
TARGET_FPS=60
MAX_ALLOWED_LATENCY_MS=40.0
SNN_SUBSTEPS=8
RESPAWN_DETECTION_THRESHOLD=0.68
```
*(Для работы онлайн с сервером FlyWire CAVE можно указать персональный токен в `FLYWIRE_API_TOKEN`, однако локальный эталонный граф коннектома уже собран и работает полностью офлайн).*

### 3. Калибровка окна игры Desktop Polytrack
Откройте игру **[Polytrack](https://kodub.itch.io/polytrack)** и откалибруйте область экрана:
```bash
# Интерактивное выделение игрового окна мышью:
python game_harness.py --calibrate

# Или двойной клик по 1_CALIBRATE_WINDOW.bat
```

### 4. Запуск автономного автопилота дрозофилы
```bash
# Запуск в реальном окне игры Desktop Polytrack:
python main.py --weights data/brain_weights_best.pt

# Или двойной клик по 2_RUN_AUTOPILOT.bat
```
**Горячие клавиши в окне пилота:**
- `SPACE` — Пауза / Возобновление автономного пилотирования.
- `M` — Переключение Ручной / Автономный режим.
- `R` — Сброс заезда в игре.
- `Q` или `ESC` — Безопасный выход с отпусканием всех клавиш.

### 5. Обучение пластических слоев (Evolution Strategies)
```bash
# Обучение в живом окне Desktop Polytrack:
python trainer.py --live --generations 10 --population 8

# Или двойной клик по 4_TRAIN_AGENT.bat
```

### 6. Управление весами мозга и откат (Brain Manager)
Система предоставляет надежное управление контрольными точками мозга дрозофилы:
```bash
# Интерактивное консольное меню:
python brain_manager.py
# (или двойной клик по 8_MANAGE_BRAIN.bat)

# Быстрые команды CLI:
python brain_manager.py --status           # Просмотр статуса, лучшего фитнеса и чекпоинтов
python brain_manager.py --reset-baseline   # Сброс к исходному биологическому состоянию
python brain_manager.py --rollback         # Откат к результатам прошлой тренировочной сессии
python brain_manager.py --list             # Список всех архивных копий
python brain_manager.py --restore <path>   # Восстановление конкретного чекпоинта
```
При каждом сбросе или откате текущие веса автоматически сохраняются в архив `data/checkpoints/` с фиксацией поколения и фитнеса, поэтому ни один результат обучения никогда не теряется.

### 7. Диагностика зрения и глаз мухи
Чтобы проверить, действительно ли сетчатка дрозофилы воспринимает живой экран PolyTrack:
```bash
# Экспресс-диагностика с генерацией фото-доказательства:
python retina.py --check-sight
# (или двойной клик по 9_CHECK_FLY_VISION.bat)

# Живой интерактивный дашборд сетчатки (с окном PolyTrack):
python retina.py --stream --live-screen
# (или двойной клик по 5_VIEW_RETINA_DASHBOARD.bat)
```
Результат проверки сохраняется в `data/fly_sight_diagnostic.png`, где наглядно сопоставлены:
1. Живой кадр игры с автомобилем и интерфейсом.
2. Тепловая карта возбуждения 512 бинокулярных омматидиев.
3. ON / OFF рецепторные каналы и векторы HRC оптического потока.
4. Растр генерируемых пуассоновских спайков.

### 8. Демонстрация прозрачного оверлея нейросети
Для предварительного просмотра работы оверлея без запуска игры:
```bash
python -m neural_overlay --demo
```
